Install & start

"Windows protected your PC" when installing

A blue window appears when you run DwaniLive-Setup.exe.

  1. Click More info.
  2. Click Run anyway.

Windows shows this for new apps that aren't yet widely downloaded. It goes away as more people install DwaniLive.

"An Application Control policy has blocked this file"

DwaniLive starts but stops with this message, or a file is "blocked by your organization".

  1. Update DwaniLive to the latest version (button in the app window, or download the installer again). Version 1.1.1 and later removed the files Windows used to block.
  2. Check Windows Security → App & browser control → Smart App Control. If it says On, DwaniLive may still be blocked until it is code-signed.
  3. On a college or company laptop, ask the IT team to allow DwaniLive.

Don't switch Smart App Control off casually: Windows can't turn it back on without a reset.

DwaniLive doesn't open, or closes straight away
  1. Open it again: if it's already running, the existing window comes back.
  2. Start menu → DwaniLive (error report). Copy what it shows and send it to us.
  3. The log file is in %LOCALAPPDATA%\DwaniLive\logs\dwanilive.log. Paste that path into the File Explorer address bar.
  4. If you see "DLL load failed", install the Microsoft Visual C++ Redistributable (x64) and try again.
"DwaniLive is being run from inside the .zip file"

Right-click the zip → Extract All… → open the extracted folder → run DwaniLive.exe. Or use DwaniLive-Setup.exe instead, which avoids this.

Antivirus deleted or quarantined a DwaniLive file
  1. Restore the file from the antivirus quarantine, or reinstall DwaniLive.
  2. Add the DwaniLive folder (%LOCALAPPDATA%\Programs\DwaniLive) as an exclusion in the antivirus.
First-time model download is stuck or very slow

The first launch downloads about 1.1 GB once. After that DwaniLive works offline.

  • Leave the window open: if the internet drops, it resumes where it stopped.
  • College networks sometimes block GitHub or Hugging Face. Connect the laptop to a phone hotspot just for the download.
  • You need about 3 GB free disk space.
"The downloaded model files are damaged or incompatible"

In the error screen click Re-download models. (Or run DwaniLive.exe --reset-models.) It downloads them again; this usually happens after an interrupted download or a full disk.

"Ran out of memory" or the laptop becomes very slow
  • DwaniLive needs about 3 GB free RAM. Close Chrome/Edge tabs, Zoom/Teams and games before starting.
  • On a 4 GB laptop, restart Windows first so nothing else is running.

Phones can't join

Phones can't open the join link / QR code doesn't load

The QR scans but the page never opens, or says "can't reach this site".

  1. Same Wi-Fi: every phone must be on the same Wi-Fi as the laptop, not on mobile data.
  2. Test with your own phone first. On the presenter page, open Check setup: the "Phone test" turns green when a phone connects.
  3. If your phone can't connect either, the network is blocking phone-to-laptop traffic (common on college and hotel Wi-Fi, called client isolation). Use a hotspot instead.
  4. Check the firewall and turn off any VPN.
Using a hotspot (the most reliable setup)

Option A: laptop hotspot. Windows Settings → Network & internet → Mobile hotspot → On. Attendees join that Wi-Fi name, then scan the QR.

Option B: phone hotspot. Turn on the hotspot on one phone, connect the laptop and all attendees to it.

Captions don't use internet data: everything stays between the laptop and the phones. A hotspot with no internet works fine.

After switching networks, re-share the QR code: the laptop's address changes.

Windows Firewall is blocking phones
  1. Close DwaniLive completely and open it again.
  2. When Windows asks to allow network access, click Yes / Allow. This adds a rule called DwaniLive LAN, once.
  3. If you clicked "No" by mistake, DwaniLive asks again the next day, or reopen it now.
VPN is on (Tailscale, office VPN, etc.)

Turn the VPN off during the session. Otherwise phones may get the VPN's address, which they can't reach.

Phone joins, then drops a few seconds later

Android phones on a Wi-Fi without internet sometimes switch back to mobile data automatically.

  • Tap the "No internet" notification → Stay connected, or
  • Turn mobile data off during the session.
"This session is full"

Your plan allows a limited number of attendees (shown on the presenter page). Upgrade from your dashboard on the DwaniLive website, or ask someone to leave so a seat frees up.

Microphone

Microphone not working / browser blocked the mic
  1. On the presenter page, open Check setup → Test microphone and speak: the bar should move.
  2. If the browser blocked it: click the lock / mic icon in the address bar → allow microphone → reload.
  3. Wrong microphone: Windows Settings → System → Sound → Input → pick the right one and check its volume.
  4. Close Zoom, Teams or Meet: some microphones can only be used by one app at a time.
"Can't hear anything: is the microphone muted?"

Check the mute switch on the mic or headset, the mute key on the laptop keyboard, and the input device in Windows Sound settings (above). Speak 15-20 cm from the microphone.

"Too loud (distorting)"

Move the microphone a little further away, or lower the input volume in Windows Sound settings. Distorted audio produces wrong words.

Using a phone as the microphone
  1. In the DwaniLive window, open Or use your phone as the mic → Show phone QR and scan it with the presenter's phone (same Wi-Fi).
  2. "Your connection is not private" appears once: tap Advanced → Proceed. It's the laptop's own certificate.
  3. Tap Start, allow the microphone, and keep the phone unlocked with calls silenced.

Only one microphone can stream at a time: stop it on the laptop page first.

Captions

Captions are slow (delay chip is red)
  • Plug the laptop in. On battery, Windows slows the processor down.
  • Close other apps, especially browsers with many tabs.
  • Speak in complete sentences with short pauses: captions appear at the end of each sentence.
Captions have wrong words
  • Speak 15-20 cm from a decent microphone; laptop built-in mics pick up the whole room.
  • Avoid music or fans near the mic.
  • Names and technical terms are the hardest. Say them clearly and, if possible, write them on your slides too.
"Demo mode: placeholder output"

The real models aren't loaded. Start DwaniLive from the desktop app (Start menu), not from developer scripts.

Licence & updates

Activation failed
  • Copy the key from your dashboard exactly (use the Copy key button) and use the same email you paid with.
  • The licence server may take ~30 seconds to wake up. Wait and try again.
  • You can always Continue with the Free plan and activate later.
Updating DwaniLive

When a new version is out, the app window shows Update now: it downloads, installs and reopens by itself. Your models and licence stay. If it fails, download DwaniLive-Setup.exe again from your dashboard and install it over the old one.

For attendees

Captions stopped on my phone
  • Wait a few seconds: the page reconnects by itself and shows a countdown.
  • Make sure your phone is still on the same Wi-Fi (and didn't switch to mobile data).
  • Reloading the page is safe: it keeps your language and the captions so far.
Make captions easier to read

Tap ⚙ Accessibility: bigger text, dark mode, high contrast, line spacing, an easy-read font, and Full screen (double-tap the captions too). Tap 💾 Save to keep a text copy of everything shown.
